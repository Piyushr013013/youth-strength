# Youth Athlete Pro

Build an ultra-comprehensive, production-ready, mobile-first athletic performance tracking web application inspired by Hevy, tailored explicitly for student athletes, youth sports competitors, and teenage fitness enthusiasts, featuring a high-contrast dark theme with a deep charcoal-black background (#090A0F), sleek glassmorphism card components, subtle glowing borders, and vibrant neon accent colors (#00FF88 electric lime, #00E5FF cyan, and #FF0055 accent red). Initialize the full application structure using React, TypeScript, Tailwind CSS, Lucide React icons, Framer Motion for smooth animations, and Recharts for data visualizations, complete with automated Supabase backend integration for user authentication, persistent data storage, custom database schemas, and user profile management. Create a multi-goal onboarding selector where users select primary athletic tracks including Sport-Specific Conditioning (Basketball, Soccer, Track and Field, Football, Swimming, Volleyball, Tennis, Baseball/Softball), Functional Strength and Hypertrophy, Speed Agility and Plyometrics, or General Movement Base and Joint Mobility. Provide two core entryways for workouts: an extensive Prebuilt Programs Library loaded with multi-week structured training plans (such as Off-Season Soccer Agility, Vertical Jump and Explosiveness, Upper Body Athletic Base, High-School Baseball Rotational Power, and Beginner Bodyweight Strength) and an Advanced Custom Workout Builder allowing complete freedom to search, create, group, and sequence exercises into custom templates. Structure the primary exercise library into five comprehensive categories with instant real-time text-search filtering, muscle-group filters, and equipment-type tags: Resistance and Weightlifting (barbell, dumbbell, kettlebell, cable, machine movements), Calisthenics and Bodyweight (pull-up variations, push-up variations, dips, muscle-ups, advanced core), Cardio and Endurance (sprints, Zone 2 running, rowing, cycling, jump rope, shuttle runs), Athletic Sport Prep (agility ladder patterns, plyometric box jumps, medicine ball throws, dynamic mobility, joint stabilization), and Recovery/Mobility drills. Build an interactive, real-time Live Workout Logger featuring live duration timers, interactive set-completion checkboxes with visual toggle states, set-type tags (Warm-up, Normal, Drop-set, Failure), superset visual grouping containers, live RPE inputs, automated rest-timer modal overlays with audio chime notifications, personal record (PR) popups with particle celebration animations, and automatic estimated 1RM calculations. Include an intelligent Performance and Training Gap Analysis dashboard that visualizes muscle volume distribution, push-to-pull ratios, upper-versus-lower body balance, and cardio-to-strength ratios through dynamic charts, generating automated feedback alerts (such as notifying the user when push volume exceeds pull volume by 1.5x and auto-suggesting corrective movements like face pulls, band pull-aparts, or inverted rows). Finally, construct an Analytics and Achievements Hub tracking lifetime tonnage lifted, active workout streaks, monthly consistency calendars, milestone badge achievements, and interactive progression line charts for exercise history, all anchored by a native-feeling mobile bottom navigation bar (Home, Routines, Live Log, Gap Analysis, Exercise Library, Profile).
